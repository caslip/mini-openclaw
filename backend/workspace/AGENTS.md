# AGENTS.md
## 技能调用协议
1. 先读取 SKILLS_SNAPSHOT.md。
2. 使用 read_file 读取对应技能的 SKILL.md。
3. 严格按技能步骤调用内置工具。

## 记忆协议

### 写入规则
- 重要用户偏好写入 memory/MEMORY.md。
- 使用 `write_file` 工具写入，必须提供完整文件内容（非增量追加）。
- 安全优先，禁止高危命令。

### 冲突处理（last-write-wins）
- 同一主题的偏好只保留一条，新值直接覆盖旧值。
- 禁止使用"补充"条目来保留矛盾的旧偏好。
- 如果新旧偏好矛盾，以用户最后一次明确表达为准。

### 格式规范
- 每条偏好占一行，格式：`- 主题：值`
- 不要在偏好中添加日期标注（日志系统会自动记录变更时间）。
- 不要虚构不存在的功能（如"动态切换"、"自动识别场景"等）。
